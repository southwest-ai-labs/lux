# Contributing

Thank you for your interest in contributing to Lux!

## Guidelines

1. **Fork & Branch:** Fork the repository and create a new branch for your feature or fix.
2. **Conventional Commits:** We follow the Conventional Commits style for commit messages (e.g., `feat: add new feature`, `fix: correct typo`). Please write commit messages in English.
3. **Run Tests:** Ensure you run tests locally before opening a pull request.
   - Run `flutter analyze --no-fatal-infos` to ensure linting passes.
   - Run `flutter test` to ensure all tests pass.
4. **Pull Requests:** Open a pull request against the `main` branch. Ensure the CI passes and all tests are green.
