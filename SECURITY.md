# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| Default branch (`main`) | :white_check_mark: |
| Latest release | :white_check_mark: |

## Reporting a Vulnerability

Please report vulnerabilities privately via GitHub Security Advisories by clicking "Report a vulnerability" on this repository. Do not open public issues for security reports.

## Response Targets

- **Acknowledge:** Within 5 business days.
- **Status Update:** Within 14 days.

We follow a coordinated disclosure model. Please note that there is no bug bounty program for this repository.
